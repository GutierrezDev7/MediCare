RESUMO
Este documento apresenta o Termo de Abertura do Projeto (TAP) para a criação de um aplicativo móvel de lembrete inteligente de medicamentos. O projeto tem como objetivo desenvolver uma solução tecnológica que apoie indivíduos no gerenciamento adequado de suas medicações, por meio de um sistema de alertas, acompanhamento remoto e funcionalidades avançadas de segurança. O aplicativo integrará tecnologias, priorizando a acessibilidade universal e o cumprimento de regulamentações de privacidade. Com um investimento estimado de R$ 17.500,00 e um período de execução de 6 meses, o projeto almeja reduzir em 80% os casos de esquecimento de doses e melhorar consideravelmente a adesão aos remédios e tratamentos médicos.




ABSTRACT
This document presents the Project Opening Term (TAP) for the development of a mobile application for intelligent medication reminders. The project aims to create a technological solution that helps people correctly manage their medications, through a notification system, remote monitoring and advanced security features. The application will incorporate technologies, with a focus on universal accessibility and compliance with privacy standards. With an estimated investment of R$ 17,500.00 and a 6-month execution period, the project seeks to reduce missed doses by 80% and significantly increase adherence to medical treatments.

2. VISÃO GERAL DO PROJETO
O projeto "Lembrete Inteligente de Medicamentos" é uma iniciativa inovadora que visa desenvolver uma solução tecnológica avançada para auxiliar pessoas na administração correta de seus medicamentos. O aplicativo móvel incorporará um sistema inteligente de notificações, incluindo alertas sonoros e visuais configuráveis, lembretes por push notification e confirmação de medicação tomada.
Nossa solução implementará um gerenciamento avançado de medicações, oferecendo cadastro detalhado de medicamentos e doses, histórico completo de administração e relatórios abrangentes de aderência ao tratamento. Para cuidadores e familiares, disponibilizaremos funcionalidades de monitoramento remoto em tempo real, alertas de doses perdidas ou atrasadas e compartilhamento de relatórios com profissionais de saúde.
O aplicativo integrará tecnologias de ponta como Machine Learning para adaptação às rotinas do usuário, Blockchain para garantia de segurança dos dados, APIs robustas para integração com sistemas de saúde e cloud computing para processamento e armazenamento seguro. Todo o desenvolvimento seguirá rigorosos padrões de segurança e privacidade, com criptografia end-to-end, autenticação de dois fatores, backup automático e total conformidade com LGPD e HIPAA.
A interface será desenvolvida com foco em acessibilidade universal, contemplando suporte a leitores de tela, opções de alto contraste, textos redimensionáveis e comandos por voz, garantindo uma experiência intuitiva e agradável para usuários de todas as idades e níveis de familiaridade com tecnologia.
3. OBJETIVOS
Objetivo Geral:
O propósito central deste projeto é criar um aplicativo móvel inovador que transformará a forma como os indivíduos administram seus medicamentos. Essa solução tecnológica será desenvolvida com as seguintes características essenciais: No que diz respeito a notificações e acompanhamento, o aplicativo incorporará um sistema sofisticado de alertas em tempo real, assegurando que os usuários não esqueçam nenhuma dose. As notificações serão altamente adaptáveis, permitindo personalizações de som, vibração e periodicidade conforme as preferências de cada usuário. Para a gestão de medicamentos, o sistema proporcionará um cadastro minucioso de cada fármaco, abrangendo nome, posologia, frequência e orientações específicas. Os usuários poderão registrar facilmente cada dose administrada, construir um histórico detalhado de uso e criar relatórios completos sobre sua conformidade com o tratamento. Sob a ótica da segurança e supervisão, o aplicativo possibilitará que cuidadores e familiares monitorem remotamente a administração dos medicamentos. Eles receberão notificações sobre doses omitidas ou atrasadas e poderão agir quando necessário, promovendo maior proteção e serenidade para todos os envolvidos. Como resultado final, almejamos obter uma melhoria expressiva na adesão aos tratamentos médicos, diminuindo falhas na administração de medicamentos e esquecimentos, o que, por consequência, resultará em melhores desfechos terapêuticos e maior bem-estar tanto para os usuários quanto para seus cuidadores.

Objetivos Específicos:
Reduzir em 80% os esquecimentos de doses de medicamentos.
Aumentar a aderência ao tratamento médico, garantindo a continuidade do uso dos remédios prescritos.
	Proporcionar maior autonomia aos pacientes, permitindo um acompanhamento facilitado e sem complicações.
	Criar um sistema que permita que cuidadores e familiares monitorem o uso dos medicamentos, garantindo segurança e controle.

5. JUSTIFICATIVA
Pesquisas indicam que aproximadamente 50% dos pacientes não seguem adequadamente suas prescrições médicas, o que acarreta complicações de saúde e elevação dos custos com internações hospitalares. Este projeto visa preencher essa lacuna ao oferecer uma solução prática e eficaz para o acompanhamento de medicamentos.

16. DICIONARIO DE DADOS
Este dicionário de dados descreve detalhadamente as estruturas das tabelas que compõem o banco de dados do sistema, seus atributos, tipos de dados, restrições e propósitos. Ele é essencial para orientar os desenvolvedores, analistas e DBAs na construção e manutenção da base de dados.
Tabela: USUARIO
Representa todos os usuários cadastrados no sistema, sejam pacientes ou cuidadores.
Campo	Tipo de Dado	Obrigatório	Descrição
id_usuario	INT (PK)	Sim	Identificador único do usuário.
nome	VARCHAR(100)	Sim	Nome completo do usuário.
email	VARCHAR(100)	Sim	E-mail único usado para login e comunicação.
senha	VARCHAR(255) (HASH)	Sim	Senha criptografada do usuário.
telefone	VARCHAR(15)	Não	Telefone opcional para contato.
data_nascimento	DATE	Não	Usado para personalização e segurança.
tipo_perfil	ENUM ('paciente', 'cuidador')	Sim	Define o papel do usuário no sistema.

Tabela: CUIDADOR
Registra os cuidadores associados a pacientes, permitindo o monitoramento remoto.
Campo	Tipo de Dado	Obrigatório	Descrição
id_cuidador	INT (PK)	Sim	Identificador único do cuidador.
id_usuario_paciente	INT (FK)	Sim	ID do paciente vinculado a esse cuidador.
relacionamento	VARCHAR(50)	Não	Define o vínculo (pai, mãe, enfermeiro, etc.).
Tabela: MEDICAMENTO
Armazena os dados dos medicamentos cadastrados pelo usuário.
Campo	Tipo de Dado	Obrigatório	Descrição
id_medicamento	INT (PK)	Sim	Identificador do medicamento.
id_usuario	INT (FK)	Sim	ID do usuário que cadastrou.
nome	VARCHAR(100)	Sim	Nome do medicamento.
dosagem	VARCHAR(50)	Sim	Dosagem (ex: 500mg).
frequencia	INT	Sim	Frequência de uso (ex: 2 vezes/dia).
data_inicio	DATE	Sim	Data de início do tratamento.
data_fim	DATE	Não	Data final prevista.
estoque	INT	Não	Quantidade restante.

Tabela: LEMBRETE
Define os alertas programados para cada medicamento.
Campo	Tipo de Dado	Obrigatório	Descrição
id_lembrete	INT (PK)	Sim	Identificador do lembrete.
id_medicamento	INT (FK)	Sim	Referência ao medicamento.
horario	DATETIME	Sim	Data e hora exata do lembrete.
status	ENUM ('PENDENTE',
'ENVIADO', 'CONFIRMADO',
'IGNORADO')	Sim	Estado atual do lembrete.
mensagem	VARCHAR(255)	Não	Texto personalizado para o usuário.

Tabela: HISTORICO
Registra o uso efetivo dos medicamentos e suas confirmações.
Campo	Tipo de Dado	Obrigatório	Descrição
id_historico	INT (PK)	Sim	Identificador do registro.
id_usuario	INT (FK)	Sim	Quem tomou o medicamento.
id_medicamento	INT (FK)	Sim	Qual medicamento foi tomado.
data_hora	DATETIME	Sim	Data e hora da administração.
status_administracao	ENUM ('ADMINISTRADO', 'NAO_ADMINISTRADO',
'ADIADO', 'CANCELADO')	Sim	Resultado da ação do usuário.
observacao	TEXT	Não	Comentários sobre o uso (ex:
efeitos colaterais).

Tabela: RELATORIO
Gera dados analíticos para acompanhamento da aderência ao tratamento.
Campo	Tipo de Dado	Obrigatório	Descrição
id_relatorio	INT (PK)	Sim	ID do relatório gerado.

Considerações sobre Segurança e Privacidade
	Senhas devem ser armazenadas de forma segura com hashing (bcrypt, Argon2.
Dados sensíveis devem ser protegidos por criptografia e respeitar a LGPD.
Logs de auditoria devem ser mantidos para ações críticas (ex: acesso de cuidador, falha de notificação).
